# Remove-DropboxTag

## SYNOPSIS

Removes a tag from a Dropbox file or folder.

## SYNTAX

```
Remove-DropboxTag [-Path] <String> [-Tag] <String> [-DriveName <String>] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Detaches the named tag from the item at `-Path`. Other tags on the
item are unaffected. Supports `-WhatIf` and `-Confirm`.

## EXAMPLES


### Example 1
```powershell
PS> Remove-DropboxTag -Path /report.pdf -Tag draft
```

Removes the ``draft`` tag from ``/report.pdf``.
